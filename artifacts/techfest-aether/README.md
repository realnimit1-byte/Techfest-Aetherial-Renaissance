# Techfest IIT Bombay — An Aetherial Renaissance

An independently created, scroll-driven WebGL experience for the 30th edition of Techfest, IIT Bombay. The visitor travels through a connected world of engraved metal, campus architecture, celestial machinery, and interactive technology forms.

**Event details:** 16–18 December 2026 · IIT Bombay, Powai, Mumbai, India  
**Theme:** An Aetherial Renaissance

> This is an independent creative concept and portfolio project. It is not the official Techfest website and does not imply endorsement by Techfest or IIT Bombay.

## Concept

The visual language is drawn from the supplied Techfest reference pack: the 30th-edition engraved wordmark, the silver TF monogram, IIT Bombay architecture, electric blue/violet apparel linework, technology-workshop posters, and the night-time light and motion of the supplied video. These references inform the scene; the posters are not reproduced as a webpage gallery.

The camera journey moves from a floating metallic relic into a campus passage, through a rotating “30” portal, across selectable technology realms, and into a final Techfest frame. Scroll controls the Three.js camera and world continuously.

## Features

- Real-time Three.js/WebGL environment with a scroll-driven camera timeline.
- Pointer-responsive camera, metallic artifact, lights, and portal.
- Six selectable 3D realms: AI / deep learning, cybersecurity, robotics, electric mobility, drone technology, and workshops.
- Select realms by clicking the 3D forms or using the keyboard-accessible controls.
- Responsive layout, reduced-motion control, WebGL fallback, and readable HTML content.
- A discreet College Ambassador identity terminal for Nimit / UPES. It does not expose personal contact details.
- Deterministic ambient point-cloud data generated by C and validated by Python.

## Technology

- **C11:** creates the repeatable ambient particle field.
- **Python 3 standard library:** compiles the C generator, validates its output, and writes the JSON asset used by the browser.
- **HTML and CSS:** semantic story content, navigation, and responsive presentation.
- **JavaScript and Three.js:** the required browser-side WebGL renderer, camera timeline, pointer interactions, and accessible controls.
- **Vite:** local development and static production builds.

There is no database, authentication, or runtime API dependency. The built website is static and can be hosted on Replit, Vercel, or GitHub Pages.

## Screenshots / demo

The Replit preview is the live demo. For a short screen recording, begin at the Aetherial Renaissance title, scroll through the campus passage and 30th-edition portal, select a few realms, then finish on the departure frame. The chapter rail can be used to move between major parts of the journey.

## Run locally

Requirements: Node.js, pnpm, Python 3, and a C compiler available as `cc` or `gcc`.

From the repository root:

```sh
pnpm install
pnpm --filter @workspace/techfest-aether run dev
```

The development command runs the Python asset generator before Vite starts. The generated file is `public/data/aether-field.json`.

## Build

```sh
pnpm --filter @workspace/techfest-aether run typecheck
pnpm --filter @workspace/techfest-aether run build
```

The static site is written to `artifacts/techfest-aether/dist/public`.

To serve the built files with Python’s standard library:

```sh
pnpm --filter @workspace/techfest-aether run serve:python
```

By default, Python serves the site at port 8000; set `PORT` to choose another port.

## Deployment

### Replit

Open the app preview from the project. The managed web workflow serves the Vite app; the production build is static.

### Vercel

Set the project root to the repository root. Use this build command:

```sh
pnpm install --frozen-lockfile && BASE_PATH=/ PORT=4173 pnpm --filter @workspace/techfest-aether run build
```

Set the output directory to `artifacts/techfest-aether/dist/public`. The build environment needs Python 3 and `cc`/`gcc` for the small C asset generator.

### GitHub Pages

For a repository published at `https://<user>.github.io/<repository>/`, build with the repository path as Vite’s base:

```sh
pnpm install --frozen-lockfile
BASE_PATH="/your-repository/" PORT=4173 pnpm --filter @workspace/techfest-aether run build
```

Replace `your-repository` with the actual repository name, then publish the contents of `artifacts/techfest-aether/dist/public` as the Pages artifact. For a user/organization site at the domain root, use `BASE_PATH=/`.
